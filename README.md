# Some-exact-results-on-Lindley-process-with-Laplace-jumps
This matlab code reproduces and confirms the calculations showed in the article: https://www.mdpi.com/2227-7390/13/7/1166

To run the code:
 1. Download the folder and leave the same file structure.
 2. From the folder `position` run position_sim_teoVSemp.m to generate the theoretical and empirical density of the position of the process at time `n`.
 3. From the folder `stopping` run stopping_sim_teoVSemp.m to generate the theoretical and empirical distribution of the first passage time through a boundary `h`.
